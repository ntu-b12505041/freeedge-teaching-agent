# FreeEdge Teaching Agent

Automated Teaching Monster API for ML2026 bonus homework.

- Receives standardized JSON requests.
- Generates an English teaching video, WebVTT subtitles, and slides PDF.
- Uses free Edge neural TTS by default (`TTS_PROVIDER=edge`).
- Includes a Render Blueprint for public HTTPS deployment.

See `README.zh-TW.md` for local usage notes.
